# Project-Bool
Project bool is the newest creation of Runtime Productions!
# 💲 Will this game be free?
Yes, this game will be completely free!
# 🥱 What can you do in this game?
In this game, you will be able to play in a fun story mode, play with others and create your own levels!
# 😨 Will all of these features come with the 1st release?
Sadly, no. I am a solo developer, meaning i cannot promise this on release. I have previously attempted to make this game multiplayer, but it didn't turn out well. However, I will aim for the "Create" Gamemode to come on release!
